Canadian FHS Tools (Fetal Health Surveillance)
A suite of educational tools designed for Canadian perinatal care providers and students, adapted from the SOGC 2020 Fetal Health Surveillance (FHS) Guidelines.

🚀 **Live Demo**
Access the tools here: [FHS Tools Dashboard](https://justanobnurse.github.io/fhs-tools/index.html)

🛠 Included Tools
CEFM Classifier Systematically classifies Electronic Fetal Monitoring (EFM) strips into Normal, Atypical, or Abnormal categories.

Deceleration Identifier A step-by-step tool to differentiate between Early, Late, prolonged and Variable decelerations, including uncomplicated and complicated variables.

IA Classifier (Intermittent Auscultation) Guided classification for IA.

MVU Calculator A dynamic calculator for Montevideo Units (MVUs) using Intrauterine Pressure Catheter (IUPC) resting tone and peak measurements.

Tachysystole Identifier Quickly assesses uterine activity to identify tachysystole thresholds based on the multuple available definitions of tachysystole.
