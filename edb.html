Estimated Date of Birth Calculator

Calculate an estimated date of birth, estimated LMP, or current gestational age using common pregnancy dating methods.

Educational Use Only:

This calculator is intended for educational reference only. Pregnancy dating should be confirmed using clinical judgment, local policy, and appropriate provider assessment.

Calculate EDB from LMP or Ovulation Date

If no ovulation date is entered, this uses Naegele’s rule: LMP + 280 days.

If entered, this will be used instead of LMP. EDB is calculated as ovulation date + 266 days.

Defaults to today’s date.
